# Gokarna Coastal Escape — Group Trip Companion

A single-file interactive web app built for our Gokarna weekend road trip, featuring:
- **Road Trip Jukebox:** Preloaded with *Thalaivan Nirandharam (Jana Nayagan)* as the default opening track, plus a crew song queue with YouTube links and voting.
- **Curated Gokarna Guide:** Filterable recommendations for Beaches (Kudle, Om, Half Moon, Paradise), Food & Cafes (Namaste Cafe, Mantra Cafe, Prema Hilltop), and Stays/Resorts with Google Maps integration.
- **Group Expense Tracker & Smart Settlement Calculator:** Log expenses in ₹, track who paid, calculate simplified settlements, use the built-in arithmetic bill calculator, and export a WhatsApp-ready summary.
- **Crew Scratchpad & Checklist:** Persistent browser storage (`localStorage`) for notes and packing reminders.

## Publish on GitHub Pages
1. Create a new repository on GitHub (e.g., `gokarna-trip`).
2. Upload `index.html` (and `README.md`) to the root of the repository.
3. Go to **Settings → Pages**, set **Source** to `Deploy from a branch` (`main` / `root`), and click **Save**.
4. Share your live GitHub Pages link with the crew!
